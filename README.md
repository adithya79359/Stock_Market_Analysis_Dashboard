 Stock Market Analysis Dashboard

 A Python project for analyzing stock market data using **yfinance**, **Pandas**, **Matplotlib**, and **Plotly**
 ## Features
- Download stock price data
- Closing price visualization
- Moving Average analysis
- Daily Return calculation
- Candlestick charts
- Compare multiple companies

## Technologies Used
- Python
- Pandas
- yfinance
- Matplotlib
- Plotly
